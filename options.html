번역기 설정

현재 PC에 로그인된 Codex CLI를 연결합니다.

기본값을 그대로 사용해도 됩니다. 외부 주소는 보안을 위해 허용하지 않습니다.

bridge\\start-bridge.cmd를 실행하면 CMD 창에 토큰이 표시됩니다. API 키가 아니며 이 PC의 브리지 연결만 보호합니다.

기본 `120×80px`보다 작은 표시 영역과 원본 파일은 아이콘으로 간주해 제외합니다.

기본값 3을 권장합니다. 값을 높이면 빨라질 수 있지만 Codex 사용량 제한과 PC 메모리 사용량도 함께 증가합니다.

이미지 합성 결과가 품질검수를 통과하지 못할 때 자동으로 재합성·재검수할 최대 횟수입니다.

원본 이미지 URL을 직접 내려받아 처리하므로 다른 탭을 보거나 Chrome을 최소화해도 됩니다. 원본을 내려받을 수 없는 특수 이미지만 화면 캡처를 사용합니다.

처리 범위

현재 페이지에 포함된 이미지 원본을 확장 프로그램이 직접 내려받아 로컬 브리지로 전송합니다. 브리지는 로그인된 Codex CLI를 읽기 전용·일회성 모드로 실행하며, 임시 이미지는 처리 직후 삭제합니다. 외부 서버에는 Codex가 사용하는 서비스 외에 이미지를 전송하지 않습니다.
