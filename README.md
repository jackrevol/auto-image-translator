# 이미지 한글 번역기 (Auto Image Translator) 2.8.6

Chrome 페이지와 ZIP 만화를 한 번에 지원하는 일본어 → 한국어 이미지 번역기입니다. API 키 없이 이 PC의 Codex CLI에 저장된 ChatGPT 로그인 세션을 사용합니다. ZIP 실행 파일에는 브리지, Node.js 런타임과 이미지 렌더러가 모두 포함됩니다.

> 현재 Windows용 로컬 프로그램으로 개발되었습니다. 번역할 이미지가 Codex 작업에 첨부되므로 사용 중인 ChatGPT/Codex 계정의 이용 정책과 사용량 제한이 적용됩니다.

## 목적

웹 만화나 ZIP으로 보관된 일본어 만화 이미지를 읽을 때 매번 OCR 결과를 복사하고 번역문을 수동으로 식자해야 하는 과정을 줄이는 것이 목적입니다. 단순히 번역문을 이미지 위에 덮는 대신 다음 품질을 중점으로 처리합니다.

- 세로쓰기와 말풍선 단위로 일본어를 인식하고 문맥에 맞는 한국어로 번역
- 일본어 원문을 섬세하게 제거하면서 말풍선 테두리, 인물, 배경 선화와 망점 보호
- 원문의 글자 크기, 색상, 굵기, 외곽선과 배치를 가능한 한 유지
- 합성 결과를 원본과 다시 비교하고 잔상, 누락, 오역과 조판 문제를 자동 재검수
- 먼저 끝난 이미지를 즉시 교체하거나 ZIP 결과에 반영하여 긴 작업의 대기 시간 단축

이 프로젝트는 범용 문서 OCR보다는 흑백·컬러 만화, 말풍선, 세로 대사와 효과음 번역에 맞춰져 있습니다.

## 통합 구조

```text
Chrome 확장 프로그램 ─┐
                     ├─ 127.0.0.1 로컬 브리지 ─ Codex CLI ─ 고정밀 만화 렌더러
ZIP 데스크톱 앱 ─ 내장 브리지 ┘
```

두 입력 방식은 같은 OCR 강화, 글자 영역 검출, 원문 제거, 한국어 조판, 병렬 처리 코드를 사용합니다. 따라서 브리지의 품질 개선이 Chrome과 ZIP에 동시에 적용됩니다.

OCR용 `codex exec`는 ChatGPT 로그인 정보만 공유하고 사용자의 Codex 플러그인·MCP·후크 설정은 불러오지 않습니다. 따라서 OCR 보조 작업이 Chrome 제어 세션이나 별도 브라우저 탭을 만드는 일을 방지합니다.

## 주요 기능

### 공통 번역 엔진

- 일본어 이미지 텍스트 인식과 자연스러운 한국어 만화 번역
- 처리 방식을 `로컬 정밀 렌더`와 `Codex 대사 작업 시트 렌더` 중에서 선택
- 작업 시트 렌더 모드는 전체 이미지를 위임하지 않고 감지된 문구 주변 크롭을 겹치지 않는 타일로 결합해 Codex 이미지 편집으로 처리한 뒤 코드로 원래 좌표에 재조립
- Codex 생성 이미지는 안전한 생성 폴더인지 확인하고 원본 크기의 무손실 WebP로 정규화한 뒤 임시 결과를 정리
- 원본·OCR 강화본·0~1000 좌표 기준본 교차 판독
- 저해상도 세로 글자를 옅은 회색 선화에서 분리하는 고대비 글자 전용 기준본
- 로컬 렌더는 이미지마다 `정밀 판독 → 누락·좌표 독립 검수 → 번역·문맥 교정 → 합성 결과 시각 검수` 품질 패스
- Codex 작업 시트 렌더는 `정밀 판독 → 번역 교정 → 대사 크롭 결합 → Codex 식질 → 코드 재조립 → 전체 시각 검수` 순서로 처리
- 시각 검수 미통과 시 교정본을 다시 합성해 사용자가 선택한 최대 1~5회 자동 검수하며, 매회 실제 재합성 이미지를 다음 검수에 사용
- 선택 횟수까지 미통과한 결과는 `사용자 검수 필요`로 표시하고 ZIP은 선택 이미지 추가 검수, 웹은 해당 이미지 우클릭으로 1회씩 수동 반복
- 다른 ZIP 이미지가 처리 중이어도 `사용자 검수 필요` 행의 추가 검수 버튼을 활성화하고, 요청을 예약해 1차 ZIP 저장 직후 자동 실행
- 번역이 끝난 이미지부터 `선택 결과 보기` 또는 행 더블클릭으로 프로그램 안에서 확대·축소 검수
- 검은 배경의 흰색·회색 대형 효과음을 찾기 위한 밝은 글자 반전본과 어두운 고대비 패널 최대 4개 상세 크롭 생성
- 대형 효과음은 굵은 원문 획을 제거하면서 패널을 가로지르는 광선·비산물·망점은 보호하도록 별도 합성 규칙 적용
- 1차 합성본을 원본과 다시 비교한 뒤 잔상, 선화 손상, 배치, 글자 크기와 오역을 교정하고 최종 재합성
- 원문 제거 영역과 한국어 조판 영역 분리
- 말풍선 테두리와 선화를 보호하는 글자 획 기반 인페인팅
- 불투명 배경 패널 없이 투명 레이어에 한국어만 합성
- 원문 폰트 크기, 색상, 굵기, 계열, 외곽선, 기울기, 회전 반영
- 저신뢰 OCR 문구 자동 제외
- 완전 무손실 WebP 중간 결과
- 최대 6개 병렬 번역과 작업 번호·이미지 번호별 CMD 로그

### Chrome 확장 프로그램

- 현재 페이지 전체 이미지 번역
- 이미지 우클릭으로 특정 이미지 한 장만 번역
- `<img>`, `<canvas>`, `<svg>`, CSS 배경 이미지 지원
- 원본 URL 직접 다운로드, 불가능한 경우에만 화면 캡처 대체
- 먼저 완료된 이미지부터 즉시 교체
- 번역 지우기로 원본 복원
- 다른 탭을 보거나 Chrome을 최소화해도 URL 기반 이미지는 계속 처리

### ZIP 데스크톱 앱

- ZIP 드래그앤드롭과 출력 경로 선택
- PNG, JPG/JPEG, WEBP, BMP 지원
- ZIP 내부 경로, 파일 순서, 주석, 비이미지 파일 보존
- 결과를 원본 파일 확장자로 다시 저장
- 이미지별 실패 시 해당 원본을 유지하고 다음 이미지 계속 처리
- 1~6개 병렬 실행, 진행률, 취소, 결과 폴더 열기
- ZIP 번역 실행 중에도 병렬 이미지 수를 1~6개로 즉시 조절하며 증감 내용을 상세 기록에 표시
- 이미지별 처리 방식에 맞춘 단계와 `자동 검수 1~선택 횟수(최대 5회) → 최종 생성 → ZIP 저장 → 완료/사용자 검수 필요` 진행표
- ZIP 이미지 56×56 섬네일과 웹 이미지 상태형 미리보기
- 출처·번호·파일명·현재 단계·상세 열 제목 클릭 정렬
- 여러 행 선택 후 이미지 단위 스킵, 실행 중 Codex 요청 즉시 중단 및 원본 보존
- 진행 단계가 갱신되어도 사용자가 보고 있던 진행표 스크롤 위치 유지
- 번역 중 창의 `X`를 누르면 `전부 취소하고 종료 / 최소화 후 계속 / 돌아가기`를 선택
- `전부 취소 후 종료` 버튼은 ZIP 대기열과 실행 중인 모든 브리지·Codex 이미지 작업을 즉시 중단하고 미완성 임시 ZIP을 폐기
- 최대 5회 재합성·시각 검수가 오래 걸려도 ZIP·Chrome 연결을 최대 60분 유지
- Chrome 웹 번역도 같은 진행표에 표시하며 출처와 브리지 작업 번호로 ZIP·탭별 요청을 분리
- 브리지 시작, 상태 확인, Codex 로그인 버튼
- 앱 시작 시 내장 브리지 자동 실행, 앱 종료 시 자동 정리
- 브리지 CMD 대신 앱의 진행 기록에 실시간 브리지 로그 표시
- 완성 파일 기본 이름: `원본이름_ko.zip`

## 사용 환경

### 릴리스 실행 파일을 사용할 때

- Windows 10/11 x64
- 인터넷 연결
- 설치 및 ChatGPT 로그인이 완료된 Codex CLI
- Chrome 확장 기능을 함께 쓸 경우 Google Chrome 또는 Chromium 계열 브라우저

ZIP 데스크톱 실행 파일에는 Python, Node.js, 로컬 브리지와 `sharp` 렌더러가 포함됩니다. 따라서 실행 파일 사용자는 Python과 Node.js를 별도로 설치할 필요가 없습니다. 단, 번역 요청을 보내는 Codex CLI는 별도로 설치되어 있어야 합니다.

### 소스에서 실행하거나 빌드할 때

- Windows PowerShell 5.1 이상 또는 PowerShell 7
- Node.js 18 이상과 npm
- Python 3.10 이상
- Codex CLI 및 ChatGPT 로그인
- Chrome 확장 기능 개발자 모드를 사용할 수 있는 브라우저

Codex 로그인 상태는 다음 명령으로 확인합니다.

```powershell
codex login status
```

로그인되어 있지 않으면 다음 명령을 실행하고 안내에 따라 브라우저에서 로그인합니다.

```powershell
codex login
```

## 설치 방법

### 권장: GitHub Release 실행 파일

1. 저장소의 [Releases](https://github.com/jackrevol/auto-image-translator/releases)에서 최신 `Image-Korean-Translator-ZIP-<버전>.exe`를 내려받습니다.
2. Codex CLI가 로그인되어 있는지 `codex login status`로 확인합니다.
3. EXE를 실행합니다. 앱이 내장 브리지를 자동으로 시작하고 연결 상태를 표시합니다.
4. Chrome 번역도 사용할 경우 아래의 `Chrome에서 사용` 절차로 확장 프로그램을 로드합니다.

### 소스 코드 설치

저장소를 복제한 뒤 Node 의존성을 설치합니다.

```powershell
git clone https://github.com/jackrevol/auto-image-translator.git
cd auto-image-translator
npm install
```

ZIP 데스크톱 앱을 소스에서 실행하려면 루트의 실행 스크립트를 사용합니다. 첫 실행 시 `desktop/.venv`를 만들고 Python 의존성을 설치합니다.

```cmd
start-zip-translator.cmd
```

브리지만 독립적으로 실행하려면 `bridge\start-bridge.cmd`를 실행합니다. CMD에 표시된 `연결 토큰`과 `Codex: Logged in using ChatGPT` 상태를 확인하세요.

## Chrome에서 사용

1. ZIP 데스크톱 앱을 실행하거나 `bridge\start-bridge.cmd`로 로컬 브리지를 먼저 실행합니다.
2. Chrome 주소창에 `chrome://extensions`를 입력합니다.
3. 오른쪽 위의 `개발자 모드`를 켭니다.
4. `압축해제된 확장 프로그램을 로드합니다`를 누르고 복제한 저장소의 루트 폴더를 선택합니다.
5. 확장 프로그램 팝업에서 `연결 설정`을 열고 앱 또는 브리지 CMD에 표시된 주소와 연결 토큰을 저장합니다.
6. 자동 재검수 횟수와 병렬 이미지 수를 원하는 값으로 설정합니다.
7. 번역할 페이지에서 확장 프로그램의 `현재 페이지 전체 번역`을 누릅니다.
8. 한 장만 처리하려면 해당 이미지를 우클릭하고 이미지 번역 메뉴를 선택합니다.

번역이 끝난 이미지는 먼저 완료된 순서대로 페이지에서 교체됩니다. `번역 지우기`를 누르면 원본으로 복원됩니다. URL에서 원본을 직접 내려받을 수 있는 이미지는 다른 탭을 보거나 Chrome을 최소화해도 계속 처리됩니다.

단축키는 `Alt+Shift+T`입니다.

## ZIP에서 사용

1. GitHub Release에서 내려받은 실행 파일 또는 루트의 `start-zip-translator.cmd`를 실행합니다.
2. 앱이 내장 브리지와 Codex 로그인 상태를 확인할 때까지 기다립니다.
3. 원본 ZIP을 창에 끌어다 놓거나 파일 선택 버튼으로 지정합니다.
4. 출력 파일 경로, 병렬 이미지 수와 자동 재검수 한도를 선택합니다.
5. `ZIP 번역 시작`을 누릅니다.
6. 이미지별 섬네일과 현재 단계를 확인합니다. 열 제목을 누르면 상태·번호·파일명 등으로 정렬할 수 있습니다.
7. 먼저 끝난 행을 선택하고 `선택 결과 보기`를 누르거나 행을 더블클릭하면 확대·축소하며 결과를 검수할 수 있습니다.
8. 불필요한 이미지는 행을 선택한 뒤 `선택 이미지 스킵`을 누릅니다.
9. 자동 검수 한도까지 통과하지 못한 행은 `사용자 검수 필요`로 바뀝니다. 해당 행을 선택하고 `선택 이미지 추가 검수`를 눌러 한 차례씩 다시 검수합니다.
10. 작업이 끝나면 기본적으로 원본 이름 뒤에 `_ko.zip`이 붙은 결과가 생성됩니다.

ZIP 앱은 브리지를 별도 CMD 창 없이 자동 실행하며 로그도 앱 안에 표시합니다. 화면의 주소와 토큰을 Chrome 확장 설정에 입력하면 ZIP 앱이 실행되는 동안 Chrome도 같은 브리지를 사용할 수 있습니다.

Windows 실행 파일의 `속성 → 자세히`에는 파일 버전과 제품 버전 `2.8.6.0`, 제품명, 설명이 포함됩니다.

### 렌더 방식 선택

- `로컬 정밀 렌더`: 기존 Sharp 기반 원문 제거·SVG 식질입니다. 빠르고 결과가 결정적이며 여러 이미지를 병렬 처리하기 좋습니다.
- `Codex 대사 작업 시트 렌더`: 전체 이미지에서 먼저 OCR 강화·좌표 검수·번역 교정을 수행한 뒤, 확정된 문구와 말풍선 주변을 크롭합니다. 최대 4개 크롭을 회색 여백으로 분리한 작업 시트 한 장에 배치해 Codex 내장 `image_generation`으로 원문 제거와 한국어 식질을 처리합니다. 결과 시트를 다시 타일로 분할하고 실제 글자 주변만 마스크 합성하므로, 인물과 배경 등 비대사 영역은 원본 픽셀을 유지합니다.

Codex 생성 파일 경로는 마지막 응답과 해당 실행의 JSON 이벤트를 함께 확인합니다. 따라서 모델이 마지막 문장에 경로를 생략해도 생성 이벤트에서 안전하게 결과를 복구하며, 병렬 이미지의 결과가 서로 섞이지 않습니다.

Codex가 생성 경로를 어떤 메시지에도 기록하지 않은 경우에는 `thread.started` 이벤트의 고유 실행 ID와 정확히 일치하는 `generated_images` 세션 폴더에서 결과를 회수합니다. 전역 최신 파일을 고르지 않으므로 여러 이미지를 병렬로 처리해도 다른 이미지 결과가 섞이지 않습니다.

Codex 실행 실패 시 종료 코드, 실패 단계, 마지막 모델 메시지, 도구 오류와 `stderr` 요약을 브리지 응답과 상세 로그에 함께 표시합니다. ZIP 프로그램에서는 실패 행을 선택하고 `선택 오류 상세`를 누르거나 실패 행을 더블클릭해 전체 사유를 확인할 수 있습니다. `prompt_cache_retention is not supported on this model`은 Codex CLI와 모델 기능 정보의 호환성 오류로 별도 판별하며 `codex update` 및 재시작 안내를 표시합니다.

Codex 대사 작업 시트 렌더는 최대 4개 크롭마다 생성 작업을 수행하므로 로컬 정밀 렌더보다 처리 시간과 Codex 사용량이 늘어납니다. 특정 작업 시트가 이미지 생성 안전 필터에 차단되면 필터를 우회하지 않고 그 시트의 크롭만 로컬 정밀 식질로 대체하며 나머지 작업 시트 처리는 계속합니다. 자동 시각 검수와 프로그램 내 결과 보기를 함께 사용하는 것을 권장합니다. API 키는 사용하지 않으며 Codex CLI에 로그인된 ChatGPT 계정을 사용합니다.

## 브리지 로그

브리지 CMD에는 Chrome과 ZIP 요청이 동일한 형식으로 표시됩니다.

```text
[14:03:21] [작업 #7 · 이미지 #23] 요청 수신 · 1.24 MB · <zip> · zip://pages/023.png
[14:03:21] [작업 #7 · 이미지 #23] OCR 강화본 준비 완료 · 1600×900 · 2.50배
[14:03:31] [작업 #7 · 이미지 #23] Codex 분석 중 · 10초 경과
[14:03:38] [작업 #7 · 이미지 #23] 일본어 문구 4개 감지
[14:03:39] [작업 #7 · 이미지 #23] 교체용 WebP 생성 완료 · 842.3 KB
[14:03:40] [작업 #7 · 이미지 #23] ZIP 이미지 저장 확인 · <zip>
```

Windows가 임시 파일을 잠시 점유해 `EBUSY` 또는 `EPERM`이 발생하면 브리지와 ZIP 출력 정리 단계에서 재시도합니다.

## ZIP 앱 실행 파일 빌드

```powershell
Set-ExecutionPolicy -Scope Process Bypass
.\desktop\build.ps1
```

완성 파일은 `desktop\dist\Image-Korean-Translator-ZIP.exe`입니다. Node.js 런타임, 브리지 코드, `sharp` 렌더러가 EXE 안에 포함되므로 `bridge` 폴더나 별도 브리지 CMD가 필요하지 않습니다.

`desktop/dist`, `desktop/build-*`, PyInstaller `.spec`, EXE와 ZIP 결과물은 `.gitignore`로 제외됩니다. 빌드 실행 파일은 소스 커밋에 포함하지 않고 GitHub Release 자산으로만 배포합니다.

## 개인정보와 제한

- API 키를 사용하거나 저장하지 않습니다. 브리지 연결 토큰은 로컬 프로그램 간 호출을 보호하기 위한 임의 문자열입니다.
- 처리할 이미지 바이트는 로컬 임시 파일을 거쳐 로그인된 Codex 서비스에 첨부되며 작업 후 삭제됩니다.
- 연결 토큰은 외부 번역 API 키가 아니라 로컬 브리지 접근을 제한하기 위한 임의 문자열이며 저장소에 커밋되지 않습니다.
- Chrome 내부 페이지와 Chrome 웹 스토어처럼 스크립트 삽입이 금지된 페이지에서는 확장 기능을 사용할 수 없습니다.
- 복잡한 그림 위의 글자나 매우 흐린 글자는 OCR과 인페인팅 흔적이 완벽하지 않을 수 있습니다.
- Chrome 확장만 단독으로 사용할 때는 `bridge\start-bridge.cmd` 창을 닫으면 안 됩니다. ZIP EXE는 브리지를 자체 관리합니다.

## 저장소에 포함하지 않는 파일

- 원본 및 번역된 샘플 이미지
- 사용자가 번역할 ZIP/CBZ와 생성된 `_ko.zip`
- `artifacts/` 아래의 OCR 중간 결과와 품질 비교 이미지
- `node_modules`, Python 가상 환경과 캐시
- PyInstaller 빌드 디렉터리, `.spec`, EXE/MSI
- 로컬 브리지 연결 토큰, 로그와 임시 파일

최종 Windows 실행 파일은 소스 저장소가 아니라 [GitHub Releases](https://github.com/jackrevol/auto-image-translator/releases)에만 등록합니다.
